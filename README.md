# 📊 Sales Performance Dashboard

An interactive **Power BI Sales Dashboard** designed to analyze sales performance through key metrics and visualizations. This dashboard enables users to monitor trends, compare regional performance, and explore customer purchasing behavior using interactive filters.

---

## 📌 Project Overview

The dashboard provides a comprehensive view of sales performance by presenting key business metrics, trends, and insights in a user-friendly format. It helps stakeholders make informed decisions through interactive visualizations and data-driven analysis.

---

## 🎯 Objectives

- Monitor overall sales performance.
- Analyze sales trends over time.
- Compare sales across different regions.
- Evaluate customer types and sales channels.
- Identify top-performing sales representatives.
- Create an interactive dashboard for business insights.

---

## 🛠️ Tools Used

- Power BI
- Microsoft Excel (CSV)
- DAX (Data Analysis Expressions)

---

## 📂 Dataset

The dataset includes the following fields:

- Product ID
- Sale Date
- Sales Representative
- Region
- Sales Amount
- Quantity Sold
- Product Category
- Unit Cost
- Unit Price
- Customer Type
- Discount
- Payment Method
- Sales Channel
